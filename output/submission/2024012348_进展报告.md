## 4. 安全设计

威胁模型覆盖直接规则覆盖、伪造管理员、隐藏提示与密钥索取、编码指令、角色越狱、工具胁迫、边界伪造和记忆投毒。任何来自用户或检索材料的授权声明均不提升实际权限；应用没有命令执行工具，也不将模型输出交给工具执行。

为降低误杀，检测同时关注动作和对象，并允许明确的概念解释、攻击分析与防御问答。问题中出现“Token”“密码”“攻击”本身不会触发拒绝。对含后续执行要求的分析包装继续检测。

## 7. 环境与复现步骤

建议 Python 3.10 或更新版本，安装 requirements.txt 中的 requests。无需公开数据集即可运行正常问答；离线及批量评估时通过命令参数传入数据集路径。

python -m pip install -r requirements.txt
python setup_token.py --token-file "C:\路径\2024012348.token.json"
python -m unittest discover -s tests -v
python eval_offline.py --dataset "C:\路径\public_dataset.jsonl" --output-dir output/offline

连接校园网或课程 VPN 后，先做接口与少量完整链路验证，再进行全量评估，避免在网络失败时重复提交请求。

python smoke_api.py --output output/api_smoke.json
python main.py --query "什么是最小权限原则？"
python eval_dataset.py --dataset "C:\路径\public_dataset.jsonl" --limit 10 --concurrency 1 --stop-on-error --output-dir output/small_online

smoke_api.py 在本人个人库创建或复用演示记录，以验证建库、上传、检索功能；不会写入公共库，也不删除任何库或文件。正式问答仍使用 common_dataset。联网成功后可去掉 --limit，按 README 中命令生成完整逐题评估与汇总。
