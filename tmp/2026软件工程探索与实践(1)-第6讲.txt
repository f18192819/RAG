如何优化提示词
n 如何制定清晰、可落地的提示词优化标准？
l 考虑准确性：可以针对输出文本基于术语准确率指标进行评估，即答案是否包含关键
词。
l 考虑逻辑性：可以用 Python 的spaCy或jieba等自然语言处理库，提取回答中的 “逻辑
节点”，校验是否符合 “问题定位→核心分析→解决方案” 的结构。
l 考虑简洁性：通过代码统计 “核心信息长度” 与 “总文本长度” 的占比，过滤无关
信息。
l 建议提示词优化标准嵌入到代码中，实现自动化评估。

我们可以显式区分可信指令与不可信数据，降低模型误执行检索材料中指令的概率：
n 边界划分：用显式边界符号（如XML标签）包裹检索内容，并在系统提示中声明边界含义
n 数据标记：为每段检索材料加统一标记/来源编号
n 编码转换：对数据做变换（转义/编码）后再将其加入提示词中
显式标记与结构隔离能够降低间接提示注入成功率。
——Hines et al., “Defending Against Indirect Prompt Injection Attacks With Spotlighting”（CAMLIS 2024）
